# 数据云仓 · 本地优先模板

Vue 3 + TypeScript + Element Plus + ECharts，Django REST Framework 后端。提供五店模拟演示、经营看板、商品档案、运营策略、任务、账户权限和 MCP 配置入口。

**仓库中的商品标题、货号、图片、店铺和经营数字全部是独立生成的虚构示例。没有真实客户数据、账号或已连接的外部服务。**

## 三分钟开始

先安装 **Node.js 22+、Python 3.11+**。克隆仓库或解压源码，在仓库根目录打开终端：

```bash
python3 scripts/dev.py demo
```

Windows 可用 `py -3.11 scripts/dev.py demo`。脚本会安装前端依赖，在本机启动；打开 <http://127.0.0.1:5173/demo>。纯演示不需要数据库、密钥或登录，操作刷新后重置。首次安装需要联网下载公开依赖。

要使用自己的数据和 MCP：

```bash
python3 scripts/dev.py full
```

打开 <http://127.0.0.1:5173/login>。初始用户名在本地 `.env` 的 `ADMIN_USERNAME`，密码在 `ADMIN_PASSWORD`。每份安装随机生成，不存在公用默认密码。不要把 `.env` 发给别人、贴到聊天里或提交到 Git。

登录后进入 **配置中心 → MCP 服务**，填写你自己的兼容服务地址和 Bearer 凭据，测试连接并发现工具，再配置数据同步。演示入口不会连接真实服务；使用真实数据请进入登录后的业务页面。

> MCP 是调用协议，不是统一的数据格式。本模板只对文档中约定的数据工具做了直接适配。其他 MCP 需要补充工具名、参数与字段映射；并非任意 MCP 地址都能自动生成看板。小时趋势也不能仅凭已有 MCP 月报工具获得。

## 让 Codex / Accio 帮你启动

把下面的提示发给能读取本地仓库并运行终端的开发智能体：

> 阅读本仓库 AGENTS.md、README.md 和 docs/QUICKSTART.md。先检查 Node/Python，再启动纯演示并验证页面。需要真实数据时按 docs/MCP.md 配置我自己的 MCP，密钥由我在本地填写，不读取其他项目的凭据。只操作本地，报告启动地址与验证结果，不自动部署或发布。

仅把 GitHub URL 发给不具备仓库读取/终端能力的聊天工具，并不能自动在电脑上安装运行。Accio 的具体权限和工具能力以你使用的客户端为准。

## 模块与边界

| 模块 | 内容 |
| --- | --- |
| 经营驾驶舱 | 实时概览、小时趋势占位/适配、月度总览 |
| 数据 BI | 多维、店铺、商品经营分析；商品档案、图片、创建天数和生命周期 |
| 运营策略 | 规则、预警、运营计划与任务流转 |
| AI 工具区 | 分析与行动任务；未配置模型时不代表真实模型推理 |
| 配置区 | 可选外部数据/模型/MCP接入、智能体凭据、用户审批与权限 |

完整本地模式默认 SQLite；Docker 示例提供 MySQL 8。所有服务默认仅监听本机。高级设置、自动同步与 MCP 智能体入口见接入文档。
